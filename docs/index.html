What is an AI detector’s verdict worth?

An open-source toolkit for testing AI-text detectors: whether a verdict on your document survives edits that change no words, what the detector’s published error rates are, and what a flag actually implies.

Open the evidence kit GitHub Auditing guide

Detector scores are being used to accuse people of misconduct. As reported in February 2026, Washington State University cancelled Turnitin’s AI detection after a third of its AI-misconduct cases were dismissed where the detector was the only evidence (memo). The question that matters is not “is this AI?” but how much anyone should trust the number — for this document, this detector version, this kind of writer. untell measures that.

Evidence kit

In your browser, offline. Generates versions of your text with exactly the same words — only quote style, spacing, line breaks differ. Score each in the detector; if the verdict changes, it was never about the words. Prints a brief.

Open it →

Evidence brief

The same test from the command line or MCP, plus the detector’s cited error rates, P(AI | flagged) by Bayes and the per-person risk. Contains a hash of your document, never the text.

Report cards

A detector over a corpus: false positives by writer group and length with 95% intervals, verdict stability, recall at a capped false-positive rate. Dated and fingerprinted; drift catches silent model changes.

Human by timestamp

untell capsule builds a human corpus from git history before ChatGPT’s release, with the commit and date on every document.

The arithmetic of a flag

A false-positive rate is the chance a human is flagged, not the chance a flagged person is human, and it compounds per person. Taking Turnitin’s own published figure (under 1%) at face value:

documents per honest writer   P(at least one false flag)   flagged per 1,000
     1                                1.0%                    10
    30                               26.0%                   260

From untell flagmath --detector turnitin --documents 30. The page’s calculator lets you change every input.

Quick start

git clone https://github.com/ssamba1/untell && cd untell && pip install -e .
untell brief --file essay.txt --detector local            # or gptzero, pangram, ... with a key
untell variants --file essay.txt --out kit                 # a detector with no API: score by hand
untell brief --file essay.txt --detector manual:kit/scores.csv --name turnitin --documents 12

Also a Claude Code skill (/plugin marketplace add ssamba1/untell), an MCP server and a REST API.

Questions

Can untell prove I wrote something?

No tool can. untell tests the detector. A verdict that flips on the same words is strong evidence against relying on it; a verdict that holds is only one this test could not break.

Does my text get uploaded?

Not by the browser kit — it runs entirely on your device and blocks network connections. The command-line tools run locally unless you point them at a commercial API yourself.

Is this a humanizer?

It contains a detector-in-the-loop rewriter used as a robustness probe, and its measured result is negative: it does not move a detector it has never seen. It is not for presenting machine-written work as your own where that is prohibited.

Is this legal advice?

No. It is measurement you can bring to whoever gives you advice.
